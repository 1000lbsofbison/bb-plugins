## More room for your threads

Slim Nav replaces the sidebar navigation rows with icon-only buttons and can
remove the divider beneath them. Hover tooltips and selected states keep each
destination identifiable, and screen readers still announce the full labels.

## Pick your density

Three sizes are available: compact (28px), cozy (34px) and roomy (40px). Touch
devices always use the roomy size so targets stay reachable.

## Keep your navigation preferences

Your existing order and hidden items carry over. Open **More (…) → Customize
sidebar** to reorder destinations and choose which ones appear. BB continues to
handle navigation, icons, keyboard shortcuts and split gestures.

## Enable or restore

Choose **Settings → Appearance → Navigation → Slim Nav**. Select **bb
(built-in)** to restore the original navigation.

## Requirements

Requires BB 0.42 or later and Plugin SDK 0.4.47 or later. No extra service,
account, or API key is needed. The plugin styles BB's original navigation
component, so future BB interface changes may require a plugin update.
